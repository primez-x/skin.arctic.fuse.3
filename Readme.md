# Arctic Fuse 3

This repository opens on the `omega` branch.
The Primez Kodi repository publishes the maintained skin from the `primez` branch.

Use the [Primez fork guide](https://github.com/primez-x/skin.arctic.fuse.3/blob/primez/Readme.md) for installation, settings, dependencies, tests, and publish instructions.
The `omega` branch remains available for the older skin source.
