## Performance tips

For the fastest startup and a more responsive feel:

- **Faster startup**: In Skin Settings → Startup, turn off **Wait for load** (so the skin does not wait for widgets to load before showing the home screen) and leave **Hub preloading** disabled. This reduces startup time when you prefer speed over pre-warmed widgets.
- The skin uses `effectslowdown="0"` so animations run at native speed; the UI should feel snappy on most devices.
